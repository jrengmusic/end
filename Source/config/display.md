## mouse

Mouse interaction: the Shadertoy iMouse uniform and, for shaders declaring
a mesh, camera orbit/reset/zoom. Button values: "left", "middle", "right",
or "none" (disables that one binding). The same button may be assigned to
more than one field.

+---------+--------+--------+---------------------------+--------------------------------------------------------------------------------------------------------------------------------------------------------------+
| key     | type   | value  | choices                   | comment                                                                                                                                                      |
+=========+========+========+===========================+==============================================================================================================================================================+
| enabled | bool   | true   |                           | Master switch. false disables iMouse (always reads zero) and every camera interaction below (orbit/reset/zoom), regardless of the individual button choices. |
+---------+--------+--------+---------------------------+--------------------------------------------------------------------------------------------------------------------------------------------------------------+
| imouse  | string | left   | left, middle, right, none | Button that feeds the Shadertoy iMouse uniform.                                                                                                              |
+---------+--------+--------+---------------------------+--------------------------------------------------------------------------------------------------------------------------------------------------------------+
| orbit   | string | middle | left, middle, right, none | Drag this button to orbit the camera (mesh-declaring shaders only).                                                                                          |
+---------+--------+--------+---------------------------+--------------------------------------------------------------------------------------------------------------------------------------------------------------+
| reset   | string | middle | left, middle, right, none | Click (press+release, no drag) this button to reset the camera to its defaults.                                                                              |
+---------+--------+--------+---------------------------+--------------------------------------------------------------------------------------------------------------------------------------------------------------+
| zoom    | string | wheel  |                           | Camera zoom is always driven by the mouse wheel — fixed, not a configurable button choice. Documented here for completeness only.                            |
